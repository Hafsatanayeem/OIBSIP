# ATM Interface

## Description
A Java console-based ATM Interface that allows users to securely access their bank account and perform common banking operations.

## Features
- Account number and PIN authentication
- Maximum of 3 login attempts
- Check account balance
- Withdraw money
- Deposit money
- Transfer money between accounts
- Transaction history
- Exit option

## Technologies Used
- Java
- Java Collections
- Java Scanner
- Object-Oriented Programming

## Project Structure
- `Main.java` - Handles login and starts the ATM
- `ATM.java` - Provides the ATM menu and operations
- `Account.java` - Manages account details and balance
- `Bank.java` - Manages accounts and transfers
- `Transaction.java` - Represents transaction information

## How to Run

Compile the program:

`javac *.java`

Run the program:

`java Main`
